## 0.2.0 (2026-09-30)

### Features

- ticker templates carry descriptions, and the preset set expands to 15
- `profile save` accepts an optional `--description`, shown by `profile list` and `profile show`

### Bug Fixes

- the SPDX example in CONTRIBUTING no longer trips the REUSE license check

### Build

- the Homebrew cask publishes to the `oa` tap (`brew install oa/tap/tickerbox-cli`)
