# Maintainers

Who reviews and merges changes to `tickerbox-cli`, and who takes over if they
cannot.

| GitHub       | Role       |
| ------------ | ---------- |
| `@openbunny` | Maintainer |

`@openbunny` is a placeholder for the org account; replace it with a specific
maintainer's GitHub handle once one is assigned, and update
[`.github/CODEOWNERS`](.github/CODEOWNERS) to match.

## Succession

If the maintainer is unreachable for 90 consecutive days, any contributor with
a merged pull request may open a pull request naming a successor in this file
and in `.github/CODEOWNERS`; it takes effect if no OpenBunny org owner objects
within 14 days.
